# Yahtzee

A browser-based implementation of the classic Yahtzee dice game.

## About
Full Yahtzee game playable in the browser, complete with dice rolling, scoring categories, and turn management.

## Features
- Roll and re-roll dice mechanics
- Full Yahtzee scoring categories
- Score tracking across turns

## Built With
- HTML, CSS, JavaScript

## How to Run
1. Clone the repo
2. Open `index.html` in your browser
